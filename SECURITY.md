# Security Policy

The current `0.5.x` release line receives security fixes.

Before publishing exploitable details, contact the repository owner through the current contact method on the [ultrasukiyaki GitHub profile](https://github.com/ultrasukiyaki). If no private channel is available, open a minimal issue that contains no exploit details and ask for a private contact method.

Never include production logs, IP addresses, access records, keys, passwords, database credentials, site tokens, `config.php`, or other secrets in a report.
