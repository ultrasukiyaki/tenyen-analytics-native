# GeoLite2自動更新

バージョン0.8.0は、手動MMDBアップロードを維持しながらGeoLite2 City・ASNを独立して保守します。HTTPS管理画面でMaxMindアカウントIDとライセンスキーを設定します。キーは導入済み暗号鍵で暗号化し、保護済み`storage/`へ0600で保存します。UIではマスクし、ログ、JavaScript、配布物に含めず、更新時に`config.php`を書き換えません。

信頼できるホストのcronから`php bin/geolite2-update.php scheduled`を毎日実行します。有効時も週次期限の到来時だけ取得します。失敗時は6時間から最大7日まで指数バックオフします。`status`、`run`、`city`、`asn`で制限付きCLI保守ができ、非待機ロックで重複実行を防ぎます。

取得先は固定MaxMind HTTPSエンドポイントで、リダイレクトしません。圧縮ファイルは150MB・200項目までで、絶対パス、ディレクトリ遡及、重複、期待MMDB欠落、破損、City・ASN型不一致を拒否します。期待MMDBだけを保護済み一時ファイルへコピーし、既存Readerで検証後、保存先と同じ場所へ準備して原子的に置換します。有効化失敗時は以前のDBを戻し、1日超の一時ファイルを削除します。

City・ASNごとに配置・読込状態、内部設定パス、安全なファイル名、DB型、ビルド日、容量、45日超の古さ、最終試行・成功、状態、安全なエラーを保持します。ブラウザへ秘密情報やファイルシステムパスを返しません。一方の失敗が他方を無効化することはありません。

自動更新にはPHP cURLと外向きHTTPSが必要です。認証情報や外向き通信がない場合も、既存の分割手動アップロードを利用できます。MMDB、認証情報、状態、導入ロック、設定、解析、集計は配布ZIPへ含めません。
