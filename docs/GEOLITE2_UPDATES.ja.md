# GeoLite2自動更新

バージョン0.8.1は、手動MMDBアップロードを維持しながらGeoLite2 City・ASNを独立して保守します。HTTPS管理画面でMaxMindアカウントIDとライセンスキーを設定します。キーは導入済み暗号鍵で暗号化し、保護済み`storage/`へ0600で保存します。UIではマスクし、ログ、JavaScript、配布物に含めず、更新時に`config.php`を書き換えません。

信頼できるホストのcronから`php bin/geolite2-update.php scheduled`を毎日実行します。有効時も週次期限の到来時だけ取得します。失敗時は6時間から最大7日まで指数バックオフします。`status`、`run`、`city`、`asn`で制限付きCLI保守ができ、非待機ロックで重複実行を防ぎます。

取得は二段階の認証境界を使います。最初の要求だけが固定`download.maxmind.com/geoip/databases/GeoLite2-{City,ASN}/download?suffix=tar.gz` permalinkへBasic認証を送り、自動リダイレクトを無効にします。直接HTTP 200の圧縮ファイルも受け付けます。301・302・303・307・308の場合、各`Location`は絶対HTTPS URL、コード内で完全一致許可したMaxMind R2配信ホスト、ユーザー情報・フラグメントなし、ポート未指定または443でなければなりません。新しい認証情報・CookieなしcURLハンドルで署名付き成果物を取得し、追加ホップも再検証して、ループと3ホップ超過を拒否します。

署名付きURLは一時的な秘密情報です。URLとクエリをログ、状態、画面、JSONへ残しません。HTTP 401は認証情報不正、403は製品権限なし、429は後ほど再試行として区別し、その他は数値状態だけを示します。ネットワーク・TLS、リダイレクト、容量、圧縮、MMDB、有効化の失敗では、応答本文、cURL詳細、プロキシ情報、ファイルパス、秘密情報を含まない安全なメッセージを使います。

応答ヘッダーは64KB、逐次取得する圧縮ファイルは150MB、展開MMDBは100MB、圧縮項目は200件までです。絶対パス、ディレクトリ遡及、リンク、デバイス、重複、期待MMDB欠落、破損、City・ASN型不一致を拒否します。期待MMDBだけを0700ディレクトリ内の0600一時ファイルへコピーし、既存Readerで検証後、保存先と同じ場所へ準備して原子的に置換します。有効化失敗時は以前のDBを戻し、成功・例外時に要求固有ファイルを清掃し、1日超の一時ファイルも削除します。

City・ASNごとに配置・読込状態、内部設定パス、安全なファイル名、DB型、ビルド日、容量、45日超の古さ、最終試行・成功、状態、安全なエラーを保持します。ブラウザへ秘密情報やファイルシステムパスを返しません。一方の失敗が他方を無効化することはありません。

自動更新にはPHP cURLと外向きHTTPSが必要です。認証情報や外向き通信がない場合も、既存の分割手動アップロードを利用できます。v0.8.0からの更新ではスキーマ・索引を変更せず、`config.php`、`data/`、`storage/`、`storage/installed.lock`、管理者・DB認証情報、暗号鍵、サイトトークン、暗号化済みMaxMind認証情報、MMDB、解析、集計、メタデータ、除外、保存ビュー、言語設定を保持します。MMDB、認証情報、署名付きURL、状態、導入ロック、設定、解析、集計は配布ZIPへ含めません。
