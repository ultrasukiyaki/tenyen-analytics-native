# ログ寿命、エクスポート、保持

バージョン0.7.0では、認証済みCSV・JSONエクスポート、生ログ保持期間、制限付き整理、保存状態診断を追加しました。日次集計はv0.7.1で追加するため、v0.7.0で生イベントを削除すると、その詳細と統計履歴は恒久的に失われます。

## エクスポート

アクセス・イベントログ、セッション、コンテンツ集計、組織、流入元、キャンペーン、イベントを書き出せます。日付、Human/Bot、流入元、キャンペーン、イベント、コンテンツ、国、ASN、組織、注目、タグ、分析除外を、意味のあるデータ種別へ適用します。CSVでは数式として解釈され得るセルの先頭へアポストロフィを付けます。JSONは安定した`tenyen.analytics.export.v1`包絡形式です。行は非バッファ方式で取得し、逐次出力します。

IPは既定で省略します。マスク方式ではIPv4を`/24`、IPv6を`/48`として出力します。生IP方式には認証・CSRF保護に加えて、`EXPORT_RAW_IP`の完全一致確認が必要です。応答にはprivate・no-storeヘッダーを設定します。

## 保持と整理

保持期間は無期限、30、90、180、365日、または1～3650日の任意値です。プレビューにはUTC基準の境界日時、対象イベント数、異なるセッション数を表示します。整理処理は非ブロッキングのファイルロックを保持し、1トランザクション当たり最大1,000 IDを選択し、イベント除外照合だけを連鎖削除します。各バッチ後に境界日時と進捗を記録し、中断後は同じ境界から再開します。設定、注釈、タグ、保存ビュー、認証情報、鍵、トークン、MMDB、無関係なデータは削除対象にしません。

`php bin/cleanup.php preview`、`php bin/cleanup.php run`、または信頼できる日次CLI cronから`php bin/cleanup.php scheduled`を実行します。公開メンテナンスURLはありません。状態と安全な失敗表示は`storage/lifecycle.json`へ制限付き権限で原子的に保存します。

## 保存状態診断

「保存・エクスポート」画面では、データベース・イベント表容量、生イベント・異なるセッション数、最古・最新レコード、直近24か月の月別件数、現在の保持期間、最終試行・実行、次回実行、境界日時、残件数、安全なエラーを含む整理状態を表示します。

## 更新

v0.7.0ではDB表・索引を追加しません。`config.php`、`data/`、`storage/`、`storage/installed.lock`、管理者・DB認証情報、暗号化・HMAC鍵、サイトトークン、MMDB、言語設定、イベント、セッション、除外ルール、注釈、タグ、保存ビューを保持してください。既存環境は、管理者が保持設定を保存するまで`app.retention_days`を使用します。
