# 訪問者情報とホスト名表示（v0.9.0）

ダッシュボードの最近の閲覧とリアルタイムに、保存済みの国コード・国名・地域・都市を表示します。セッション一覧・詳細、訪問者詳細でも共通の表示形式を使用し、ASN・登録組織を確認できます。欠損値は `—` です。ASN登録情報やPTRホスト名はネットワーク設備の情報であり、訪問者の勤務先や本人性を証明しません。

アクセス履歴は、IPの代わりに逆引きホスト名を表示します。ツールチップと展開した詳細も同様です。未処理の場合は「ホスト名の取得待ち」、PTRなし・処理失敗の場合は「ホスト名を取得できません」と表示します。既存のブラウザ表示設定は保持するため、以前非表示にした場合は表示設定でホスト名と地域を有効にしてください。

## ホスト名更新の設定

サーバーの定期実行機能またはcronで、次のCLIワーカーを毎分実行します。アプリケーションの絶対パスを指定してください。

```cron
* * * * * /usr/bin/php /path/to/tenyen-analytics/bin/resolve-hostnames.php
```

定期実行がない場合、未取得のホスト名は取得待ちのままです。PHPのUDPストリームと `/etc/resolv.conf` のnameserver設定が必要です。先頭のDNSリゾルバーを使用し、外部の検索APIは使用しません。逆引きでは公開IPを設定済みリゾルバーへ送信します。プライベート・ループバック・リンクローカル・文書用などの非公開アドレスは処理しません。

1回に最大20個のIPハッシュを順次処理し、DNS応答待ちは500ミリ秒、処理時間の予算は15秒です。DBロックで重複起動を防ぎ、最近のイベントを優先します。成功結果は24時間、PTRなしは6時間、リゾルバー障害は1時間キャッシュします。不正・切り詰め応答は失敗として待機し、TCPへの再接続は行いません。

収集処理や管理画面表示では逆引きしません。アクセス履歴は表示対象のキャッシュを1回の照会で取得します。暗号化IP保存、HMACによるIP完全一致検索、明示的なエクスポートIP設定は維持します。

## 更新と保持期間

既存の自動スキーマ移行で `tya_hostname_cache` を追加します。既存IPハッシュを主キーとし、有効期限の索引を持ちます。イベント列の変更はありません。更新時は `config.php`、`data/`、`storage/`、導入ロック、認証情報、暗号鍵、トークン、MMDB、ログを保持し、初期設定を再実行しないでください。

ホスト名ワーカーとログ整理の成功時に、元イベントが残っていないキャッシュを削除します。ホスト名は管理者専用で、既存エクスポートには追加しません。DBバックアップも通常の個人データ保持手順に従って管理してください。

## 表示項目の対応

| 画面 | v0.9.0の表示 |
|---|---|
| 最近の閲覧 | 地域を追加し、ASN・分類を維持 |
| リアルタイム | 地域を追加し、状態・ASN・閲覧計測を維持 |
| アクセス履歴 | 地域・ネットワーク・環境の共通表示とキャッシュ済みホスト名 |
| セッション一覧・詳細 | 既存の国名・ASNに国コード・地域・都市を追加 |
| 訪問者詳細 | 完全な地域・ASN・登録組織・分類を追加 |
| 訪問者属性・組織 | 国別・ネットワーク別の集計を維持 |
| 記事・参照元・キャンペーン・イベント集計 | 集計単位を維持し、任意の国やASNを代表値として表示しない |

比較基準はWordPress v0.8.1（`6499c0f`）です。最近の閲覧・リアルタイムの地域や、Nativeに既存のASN独立列はWordPressの配置を拡張します。WordPress固有のフックや権限APIは移植しません。
